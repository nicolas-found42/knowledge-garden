# Supplied agent conversation exports

The importer retains the exact original and projects supplied message text into a readable source page. Two bounded adapters are implemented:

- Normalized JSON with `format: "knowledge-garden-conversation-v1"`, a nonempty `conversation_id`, and a `messages` array. Each message can supply `id`, `role`, `author`, RFC 3339 `date`, and string `content`.
- Codex rollout JSONL using the serialized `session_meta` and `response_item` shapes inspected at OpenAI Codex commit `18e28fe1b96db7e1d6b13584bec37c41f71b8b0e`. Supported response items are textual messages, function calls with retained argument strings, function outputs, and readable reasoning summaries. This is a bounded adapter, not a promise that every provider or every rollout record is supported.

The projection examines at most 8 MiB, 1,000 messages, and 4,000 rollout records. Originals remain complete. Unsupported records, malformed text parts, absent identities, conflicting session identities, opaque reasoning, and invalid timestamps produce explicit gaps or a failed extraction state. Missing dates stay unknown; import time does not become a message date. Supplied export order remains distinct from chronological evidence. Missing response IDs use disclosed call/output or export-row locators.

Every acquired message carries session, message identity, supplied order, role, author, date, and channel. Percent encoding protects locator fields; newlines in message text are displayed as escaped characters. A projection quote and its offsets refer to the readable projection, not original export byte positions. The evidence links retain the original, source version, and message locator.

Jev classifies meaningful message intent using a fixed catalog. Questions, proposals, attributed claims, explicit user decisions, tool reports, and reasoning events receive separate navigable targets. A literal acquired function-call record establishes recorded call intent without asking Jev to guess whether the call succeeded. Its output remains a distinct target. A tool report or model claim does not authenticate external truth. URLs remain linked occurrences until the owner explicitly imports their destinations through URL ingestion.

A well-formed intent judgment below the 0.85 threshold publishes the exact attributed message with an explicit `uncertain` intent. The supplied model outcome and probability remain diagnostic metadata; the uncertain top choice is not presented as an accepted decision. Malformed answers, invalid probabilities, and role contradictions remain recoverable failures. The current semantic request supports 1–64 projected messages and the existing 64 KiB request-text bound; larger readable exports retain their source context while semantic processing reports its limit.

Native publication validation independently binds all conversation entities, facts, relationships, and source-order evidence to exact acquired message context. It rejects promotion to observed external events, invented chronology, and conversation provenance forged by ordinary text. Conversations, individual messages, and reasoning events retain separate source identities; repeated wording does not establish shared identity or current acceptance.

## Qualification recorded during implementation

The public `Application` suite covers retained originals, linked-only URLs, unknown/malformed dates, partial Codex content, literal call/output distinction, forged provenance, quoted numeric corrections, repeated wording across sessions, ambiguous intent, and malformed provider answers. A mounted reader test uses the real public application driver to import a Codex fixture, open its call target, check exact `deploy_check` arguments and attribution, open the unchanged original, and return to the source. Shared generated Markdown escapes punctuation instead of deleting source characters.

Three synthetic live production-path imports were labeled before evaluation. The normalized five-message and Codex six-message examples completed on their first attempts with the expected modeled intents. The first adversarial eight-message import exposed the all-or-nothing confidence limitation and remained pending with zero targets. After the explicit uncertain-target change, a fresh collection published all eight attributed messages plus their conversation; two low-confidence claims remained `uncertain` intents, with probabilities 0.80 and 0.79 preserved. The original failed result remains part of the evidence. The independent adversarial labels are agent-authored, not human gold or a general accuracy measurement.

Two additional independently labeled sessions reused identical decision wording across assistant and user turns. Both completed their first live attempts with eight unique targets and no shared page IDs. The model called both assistant turns proposals where the frozen labels called them claims: exact class agreement was 4/6, and that disagreement is retained. Neither assistant turn became an owner's recorded decision; the four user choices remained separate recorded messages. This distinction between category agreement and identity/acceptance behavior is part of the recorded quality limits.

These component checks do not establish whole-branch or installed native-app qualification. Current combined checks, final Jev completion review, and independent review of the seven exact issue criteria are recorded separately before issue closure.
