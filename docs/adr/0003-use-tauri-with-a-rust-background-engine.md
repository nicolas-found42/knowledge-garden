# Use Tauri with a Rust background engine

Use Tauri 2, a Rust background engine, and a TypeScript interface for the first personal release on the owner's 16 GB Apple Silicon Mac. Keep processing active after window close through a menu-bar application that starts at login and stops on Quit, with disk-based SQLite and local meaning-search indexes, incremental work, and bounded views for the 250,000-file collection target. This foundation is selected in [Specification #1](https://github.com/nicolas-found42/knowledge-garden/issues/1); concrete libraries, packaging, accessibility, and integrated performance remain validation work rather than results established by the research prototypes.
