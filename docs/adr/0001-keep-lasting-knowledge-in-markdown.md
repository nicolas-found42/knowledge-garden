# Keep lasting knowledge in readable Markdown

Keep all lasting knowledge in readable Markdown, with granular facts, relationships, qualifications, stable identities, and evidence references inside the relevant pages; retain original assets in their original formats. Search, graph, and meaning-search indexes are derived and rebuildable, so independent reading and optional editing in ordinary Obsidian do not depend on an application database or custom plugin. [Specification #1](https://github.com/nicolas-found42/knowledge-garden/issues/1) selects this representation while leaving the exact schema, complete rebuild behavior, and real Obsidian compatibility for implementation validation.
