## Initial brainstorm concerns

1. [Knowledge formation](initial-brainstorm/01-knowledge-formation/README.md): interpret conversations, establish source support, identify entities and organize candidate knowledge.
2. [Knowledge maintenance](initial-brainstorm/02-knowledge-maintenance/README.md): distinguish lookup from maintenance, refresh dependent notes and nominate recurring procedures.
3. [Retrieval and navigation](initial-brainstorm/03-retrieval-and-navigation/README.md): acquire candidates, assemble complementary evidence, follow graph links and judge when more evidence is needed.
4. [Query and context](initial-brainstorm/04-query-and-context/README.md): compose typed queries, check source freshness, recover raw evidence and retain useful agent context.

The [collection index](initial-brainstorm/README.md) contains the combined findings, inference ledger and evidence limits. These documents inform the design discussion; they do not record an accepted product architecture.
