# Navigation and provenance

[Expanded exploration](../README.md) · [All research](../../README.md)

This concern compares the five requested experiences—wiki, source explorer, reasoning timeline, connections and focused collections—and tests whether derived records can recover the correct original evidence after a source changes.

Experiments live in [experiments](experiments/). The provenance investigation uses independently selected public specifications and pinned implementation files. Conversation URL destinations are not an input to its fetcher.

- [Navigation and provenance report](2026-09-29-navigation-and-provenance.md): five experiences, source-anchor comparisons, honest recovery/abstention metrics and content-coverage limits.
- [Explore the evidence comparison](experiments/navigation-lab/index.html): public media, controlled reasoning histories, source records and speculative connections in five local views.
- [Source anchoring laboratory](experiments/provenance-lab/README.md): exact source manifests, deterministic mutation fixtures, audited results and portable disk-recovery controls.
- [Generated wiki laboratory](experiments/wiki-lab/README.md): source structure versus separate generated prose, deliberate conversion loss, original-evidence checks and manual qualifier audit.

This is a research prototype and a comparison of alternatives. It does not select a home view, graph database or automatic promotion policy.
