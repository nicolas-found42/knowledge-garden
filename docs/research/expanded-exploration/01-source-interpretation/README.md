# Source interpretation

[Expanded exploration](../README.md) · [All research](../../README.md)

How can actual photographs, book scans, video, text, structured files and controlled histories become searchable and connected without confusing generated observations with original evidence?

- [Media interpretation report](2026-09-29-media-interpretation.md): actual public cross-format corpus, two rich traceable demonstrations, source fidelity, missed/misleading relationships, supporting-model failures, original-region/time anchors and separate costs.
- [Reproducible media lab](experiments/media-lab/README.md): acquisition manifests, native extraction, runnable changed Python file and video, 25 supporting-model requests and 113 Jev requests, raw responses, frozen labels, diagnostics and offline analysis.

The central result is a conversion boundary: extraction preserves literal book text but loses visual and temporal content; supporting perception can recover content while damaging attribution, qualification or anchors. Jev can check generated candidates against independent retained extracts and reject unsupported relationships. It cannot authenticate an unverified caption from that caption alone.

Both coding and personal-note histories in this concern were deliberately constructed. The book scan, photographed fruit, video, author article and old project implementation are real public sources. Links to a user's actual old project remain hypothetical. No private histories or conversation-URL destinations were inspected here. This is research evidence, not an accepted architecture.
